# tyweb

Minimal Next.js (JavaScript) scaffold for the "tyweb" project.

This repository is Vercel-ready. The scaffold includes a client-only placeholder component for future kinetic typography work.

Quick start

1. Install dependencies

   npm install

2. Run locally

   npm run dev

3. Build

   npm run build

4. Start production

   npm start

Deploy to Vercel

- Connect this GitHub repository to Vercel and import the project. Vercel auto-detects Next.js and the default settings should work.

Notes

- The project intentionally uses plain JavaScript (no TypeScript).
- Keep secrets out of the repo; see .gitignore which prevents committing .env and build artifacts.
